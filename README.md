## ✨ About Me

Full-stack engineer with **9+ years of experience**, specializing in **Next.js, React, and TypeScript** — building production systems that hold up under real traffic, not just demos.

My approach centers on **server-first architecture**: App Router, React Server Components, and deliberate rendering strategy (SSR / SSG / ISR) to ship interfaces that are fast by default and cheap to run at scale. I like solving the problems teams hit past the prototype stage:

- ⚡ Eliminating client–server waterfalls
- 📉 Cutting Core Web Vitals regressions
- 🗄️ Designing caching and data layers that stay correct under concurrent load
